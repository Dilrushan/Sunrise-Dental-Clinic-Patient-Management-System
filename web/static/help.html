User Help & Guide - Sunrise Dental Clinic

SUNRISE DENTAL CLINIC - SYSTEM USER GUIDE

1. Receptionist Guide

  • Register New Patient: Fill mandatory fields & 10-digit phone.
  • Book Appointment: Fill mandatory fields & 10-digit phone.
  • Search & View: Enter appointment number to retrieve records.
  • Billing: Compute consultation & treatment fees instantly.
  • Update Appointment: Select a row and change the visit type.

2. Doctor Guide

  • Log in to view assigned patient appointments.
  • Select an appointment row and choose a treatment option.
  • Click Save Prescription to record the treatment and update billing.

3. Admin Guide

  • Full access to all features.
  • Register Staff: Create new staff accounts (Admin, Receptionist, Doctor).
  • Register Patient: Register new patients with appointment details.
  • Book Appointment: Book appointments for existing patients.
  • Update/Delete: Select a row to modify or remove appointments.

4. General Notes

  • All times and dates use YYYY-MM-DD format.
  • Treatment fees are in Sri Lankan Rupees (LKR).
  • General Consultations have no fee (LKR 0).
  • Duplicate bookings for the same patient, doctor, and date are not allowed.
